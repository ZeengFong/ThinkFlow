# ThinkFlow 🧠🌊

A hackathon project for **Calgary Hacks 2026** that helps users turn abstract problems into clear, actionable subtasks using AI-powered planning and hierarchical visual flows.

---

## 🚀 Features

- **AI Problem Breakdown:** Turn complex ideas and problems into smaller, actionable tasks.
- **Visual Flow Mapping:** Organize projects and subtasks through hierarchical flow diagrams.
- **Project Management:** Create and manage projects from one central workspace.
- **Task Tracking:** Keep track of individual tasks and progress within each project.
- **File Uploads:** Upload project-related files to support planning and organization.
- **Modern Frontend:** Built with Next.js, React, TypeScript, and interactive UI components.
- **FastAPI Backend:** Handles projects, flows, tasks, uploads, and AI-powered functionality.
